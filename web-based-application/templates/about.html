About Ai-Listo

AI-powered student attention monitoring system.

Ai-Listo

Version 1.0.0

Ai-Listo is an AI-powered system designed to monitor and analyze student attention levels in real-time during classroom sessions. Built for SSS Vilage Elementary School, it uses computer vision and machine learning to provide teachers with actionable insights.

Key Features

  • Real-time student attention detection using YOLOv8
  • Pose estimation and analysis with MediaPipe
  • Live dashboard with attention scores and trends
  • Session recording and history analytics
  • Class management and scheduling

Technology Stack

  • Backend: Flask (Python)
  • Frontend: HTML/CSS/JavaScript with Jinja2 templates
  • AI Models: YOLOv8 + MediaPipe
  • Database: PostgreSQL via Supabase
  • Charts: Chart.js
